# NexusPM – Implementation Plan

## Project Overview
NexusPM is a full-featured, enterprise-grade Project Management Web Application built on the existing Laravel 12 installation.

## Environment
- **PHP**: 8.2.12
- **Laravel**: 12.64.0
- **Database**: MySQL, database name `project_m`, host `127.0.0.1:3306`
- **Frontend Build**: Vite 7 + Tailwind CSS 4

## Technology Stack
| Layer | Technology |
|---|---|
| Backend | Laravel 12 |
| Server Frontend | Laravel Blade |
| Interactive UI | Livewire 3 |
| Lightweight JS | Alpine.js |
| Styling | Tailwind CSS 4 |
| Database | MySQL |
| Auth | Laravel Breeze (Blade) |
| Roles | Spatie Laravel Permission |
| Activity Log | Spatie Laravel Activitylog |
| Charts | Chart.js |
| Drag & Drop | SortableJS |
| PDF | Barryvdh Laravel-DomPDF |
| Excel/CSV | Maatwebsite Laravel-Excel |
| Testing | Pest |
| Icons | Blade Heroicons |
